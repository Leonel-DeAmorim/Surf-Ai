# Real-Time RL Surfing Bot

A highly optimized Python pipeline that streams real-time player positions (`XYZ`, `Angles`) paired with live in game frames to a rl model.  



-Screenshot capture	47–48 FPS	
-Telemetry collection	91–93 Hz	
-Screenshot matching	100%	
-Average timestamp difference	~2.7 ms	
-Average input readiness	~34.4 ms	
-P95 input readiness	~61.6 ms	


## Prerequisites & Installation
-python 3.14.7
-Node
-Open3D
-CV2
-DXcam
